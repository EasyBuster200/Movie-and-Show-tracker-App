# EpisodeCard

An episode with its still, number, title, air date, runtime, a two-line synopsis and a watched toggle.

Pass the 16:9 still in `image`. The synopsis clamps at two lines with "Show more". Date format: `27 May 2026`; runtime: `52m`. Watched fills the eye in `accent-text` on an `accent-subtle` square, matching the poster toggles.
