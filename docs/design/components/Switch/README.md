# Switch

An on/off toggle for settings that take effect immediately (notifications, auto-backup, hide watched).

Put it at the right end of a settings row and pass the row's label as `label` so screen readers name it. On is the accent fill with an `on-accent` knob; off is `bg-raised` with a `border-strong` outline so the track stays visible on cards. Use a Switch only for instant changes; choices between options use `Chip`s.
