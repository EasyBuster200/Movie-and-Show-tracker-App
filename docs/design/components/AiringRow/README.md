# AiringRow

One upcoming episode of a tracked show: a date tile, the show and episode, and when it airs; used in Home's Airing Soon list.

List the next few airings in date order, one row per show. `when` is relative ("Tonight · 21:00", "Tomorrow", "In 2 days"); set `soon` for anything airing today so it shows in `accent-text`. Give `href` to open the show.
